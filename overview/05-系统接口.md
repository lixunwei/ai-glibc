# 系统接口模块

系统接口模块封装了操作系统核心功能：进程管理、信号处理、时间、资源控制等。

---

## 1. posix — POSIX 兼容层

### 功能概述

`posix` 模块是 POSIX 标准接口的主要实现，涵盖进程创建/执行、
文件通配符匹配、正则表达式、系统配置查询等。

### 规模

- 源文件: 286 个 .c 文件，20 个 .h 文件

### 功能分类

```
posix
├── 进程管理: fork, _Fork, vfork, execve, execvp, wait, waitpid
├── 进程创建: posix_spawn, posix_spawnp (spawn 属性/文件动作)
├── 通配符: glob, globfree, fnmatch, wordexp
├── 正则表达式: regcomp, regexec, regfree
├── 系统配置: sysconf, pathconf, fpathconf, confstr
├── 用户/组: getuid, geteuid, getgid, setuid, setgid
├── 进程组/会话: getpgrp, setpgid, setsid, getpid, getppid
└── 其他: sleep, usleep, pause, alarm
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `fork` / `_Fork` | 创建子进程 |
| `execve` / `execvp` / `execlp` | 执行程序 |
| `posix_spawn` / `posix_spawnp` | 高效进程创建 |
| `wait` / `waitpid` / `waitid` | 等待子进程 |
| `glob` / `globfree` | 路径通配符展开 |
| `fnmatch` | 文件名模式匹配 |
| `wordexp` | Shell 式单词展开 |
| `regcomp` / `regexec` / `regfree` | POSIX 正则表达式 |
| `sysconf` | 查询系统配置值 |
| `pathconf` / `fpathconf` | 查询路径配置 |
| `getpid` / `getppid` | 获取进程 ID |
| `getuid` / `geteuid` | 获取用户 ID |
| `setuid` / `setgid` | 设置用户/组 ID |
| `setsid` / `setpgid` | 会话/进程组管理 |

### 关键源文件

| 文件 | 功能 |
|------|------|
| spawn.c / spawni.c | posix_spawn 实现 |
| execve.c / execvp.c | exec 系列 |
| glob.c | 通配符展开 |
| regex.c / regcomp.c | 正则表达式引擎 |
| sysconf.c | 系统配置查询 |
| wait.c / waitpid.c | 进程等待 |

## 2. signal — 信号处理

### 功能概述

`signal` 模块提供 POSIX 信号处理接口，包括信号安装、屏蔽、等待和发送。

### 规模

- 源文件: 52 个 .c 文件，1 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `signal` | 设置信号处理函数（简易版） |
| `sigaction` | 设置信号处理（完整版） |
| `raise` | 向自身发送信号 |
| `kill` / `killpg` | 向进程/进程组发送信号 |
| `sigprocmask` | 修改信号屏蔽字 |
| `sigpending` | 查询未决信号 |
| `sigsuspend` | 原子替换屏蔽字并等待 |
| `sigwait` / `sigwaitinfo` / `sigtimedwait` | 同步等待信号 |
| `sigqueue` | 带数据发送信号（实时信号） |
| `sigaltstack` | 设置备用信号栈 |
| `sigsetjmp` / `siglongjmp` | 信号安全的非局部跳转 |

### 兼容性

- 包含 BSD 旧式接口: `sigvec`, `sigblock`, `sigsetmask`
- 包含 System V 接口: `sigset`, `sighold`, `sigrelse`
- 推荐使用 `sigaction` 替代 `signal`

## 3. time — 时间函数

### 功能概述

`time` 模块提供日历时间、时钟、定时器、时区和时间格式化相关函数。

### 规模

- 源文件: 103 个 .c 文件，2 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `time` | 获取当前时间（秒） |
| `clock_gettime` / `clock_settime` | 高精度时钟 |
| `clock_getres` | 查询时钟精度 |
| `gettimeofday` | 获取时间（微秒精度） |
| `gmtime` / `gmtime_r` | 转换为 UTC 时间 |
| `localtime` / `localtime_r` | 转换为本地时间 |
| `mktime` | 本地时间转时间戳 |
| `strftime` | 时间格式化输出 |
| `strptime` | 时间字符串解析 |
| `difftime` | 时间差计算 |
| `ctime` / `asctime` | 时间转字符串（旧式） |
| `timespec_get` / `timespec_getres` | C11 时间接口 |
| `nanosleep` / `clock_nanosleep` | 高精度睡眠 |
| `timer_create` / `timer_settime` | POSIX 定时器 |

### 关键源文件

| 文件 | 功能 |
|------|------|
| mktime.c | 本地时间归一化和转换 |
| strftime.c / strftime_l.c | 时间格式化 |
| strptime.c / strptime_l.c | 时间解析 |
| tzset.c / tzfile.c | 时区数据库加载 |
| clock_gettime.c | 高精度时钟实现 |

### 特性

- Y2038 安全（time64 支持）
- 本地化时间格式（`*_l` 变体）
- 支持所有 POSIX 时钟类型（REALTIME、MONOTONIC 等）

## 4. resource — 资源限制

### 功能概述

`resource` 模块提供进程资源限制和使用情况查询接口。

### 规模

- 源文件: 13 个 .c 文件，1 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `getrlimit` / `setrlimit` | 获取/设置资源限制 |
| `getrlimit64` / `setrlimit64` | 64 位版本 |
| `getrusage` | 获取资源使用统计 |
| `getpriority` / `setpriority` | 获取/设置调度优先级 |
| `nice` | 调整优先级 |
| `ulimit` / `vlimit` | 旧式资源限制（已废弃） |

### 资源类型 (RLIMIT_*)

- `RLIMIT_CPU`: CPU 时间限制
- `RLIMIT_FSIZE`: 文件大小限制
- `RLIMIT_DATA`: 数据段大小
- `RLIMIT_STACK`: 栈大小
- `RLIMIT_CORE`: 核心转储大小
- `RLIMIT_NOFILE`: 文件描述符数量
- `RLIMIT_AS`: 虚拟内存大小
- `RLIMIT_NPROC`: 进程数量

## 5. sysvipc — System V IPC

### 功能概述

`sysvipc` 模块提供 System V 进程间通信机制：消息队列、信号量和共享内存。

### 规模

- 源文件: 19 个 .c 文件，1 个 .h 文件

### 主要 API

| 类别 | 函数 | 说明 |
|------|------|------|
| 通用 | `ftok` | 生成 IPC 键值 |
| 消息队列 | `msgget` / `msgsnd` / `msgrcv` / `msgctl` | 消息队列操作 |
| 信号量 | `semget` / `semop` / `semctl` / `semtimedop` | 信号量操作 |
| 共享内存 | `shmget` / `shmat` / `shmdt` / `shmctl` | 共享内存操作 |

## 6. misc — 杂项系统调用

### 功能概述

`misc` 是一个 **大杂烩模块**，包含不适合归入其他类别的系统调用封装
和遗留 Unix 接口。

### 规模

- 源文件: 176 个 .c 文件，16 个 .h 文件

### 主要 API（部分）

| 函数 | 说明 |
|------|------|
| `syscall` | 通用系统调用接口 |
| `ioctl` | 设备 I/O 控制 |
| `ptrace` | 进程跟踪（调试） |
| `syslog` / `openlog` / `closelog` | 系统日志 |
| `getauxval` | 获取辅助向量值 |
| `mmap` / `munmap` / `mprotect` | 内存映射 |
| `mlock` / `munlock` | 内存锁定 |
| `gethostname` / `sethostname` | 主机名 |
| `getdomainname` / `setdomainname` | 域名 |
| `daemon` | 守护进程化 |
| `reboot` | 系统重启 |
| `mount` / `umount` | 文件系统挂载 |
| `swapon` / `swapoff` | 交换区管理 |
| `getpagesize` | 获取页面大小 |
| `select` / `pselect` | I/O 多路复用（旧式） |
| `usleep` / `ualarm` | 微秒级延时/闹钟 |

### 特点

- 包含大量 Linux 特有接口
- 包含已废弃但仍需兼容的旧接口
- 是新系统调用的暂存目录
