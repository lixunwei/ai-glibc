# 辅助组件模块

辅助组件提供特定场景下的专用功能。

---

## 1. login — 登录与终端管理

### 功能概述

`login` 模块管理用户登录记录（utmp/wtmp）、伪终端分配和登录相关操作。

### 规模

- 源文件: 47 个 .c 文件，4 个 .h 文件

### 功能分类

```
login
├── 登录记录: utmp/utmpx 读写
├── 伪终端: openpty, forkpty, grantpt, unlockpt, ptsname
├── 用户查询: getlogin, getlogin_r
└── 历史日志: updwtmp, logwtmp
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `getlogin` / `getlogin_r` | 获取当前登录用户名 |
| `getutent` / `getutent_r` | 遍历 utmp 记录 |
| `getutid` / `getutline` | 按条件查找 utmp 记录 |
| `pututxline` | 写入 utmp 记录 |
| `updwtmp` / `logwtmp` | 更新 wtmp 日志 |
| `openpty` | 分配伪终端对 |
| `forkpty` | fork + 伪终端 |
| `grantpt` | 授予伪终端从端权限 |
| `unlockpt` | 解锁伪终端从端 |
| `ptsname` / `ptsname_r` | 获取从端设备名 |

### utmp/wtmp 说明

- **utmp** (`/var/run/utmp`): 当前登录用户列表
- **wtmp** (`/var/log/wtmp`): 历史登录/注销记录
- **utmpx**: POSIX 标准化的 utmp 接口

## 2. dlfcn — 动态加载 API

### 功能概述

`dlfcn` 模块提供动态共享库的运行时加载接口，是 `elf` 模块的用户级封装。

### 规模

- 源文件: 55 个 .c 文件，2 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `dlopen` | 加载共享库（指定路径或搜索路径） |
| `dlmopen` | 在指定命名空间加载库 |
| `dlsym` | 按名称查找符号 |
| `dlvsym` | 按名称和版本查找符号 |
| `dlclose` | 卸载共享库 |
| `dlerror` | 获取最近的错误信息 |
| `dladdr` | 地址反查到符号信息 |
| `dladdr1` | 扩展地址反查 |
| `dlinfo` | 查询共享库信息 |

### dlopen 标志

| 标志 | 说明 |
|------|------|
| `RTLD_LAZY` | 延迟绑定（需要时才解析符号） |
| `RTLD_NOW` | 立即绑定（加载时解析所有符号） |
| `RTLD_GLOBAL` | 符号全局可见 |
| `RTLD_LOCAL` | 符号仅本库可见 |
| `RTLD_NODELETE` | dlclose 不卸载 |
| `RTLD_NOLOAD` | 仅查询不加载 |
| `RTLD_DEEPBIND` | 优先查找自身符号 |

### 特殊句柄

| 句柄 | 含义 |
|------|------|
| `RTLD_DEFAULT` | 默认符号搜索顺序 |
| `RTLD_NEXT` | 下一个库中的同名符号 |

### 与 elf 模块关系

`dlfcn` 是薄封装层:
```
dlopen() → __libc_dlopen_mode() → elf/dl-open.c
dlsym()  → __libc_dlsym()       → elf/dl-sym.c
```

## 3. dirent — 目录操作

### 功能概述

`dirent` 模块提供目录遍历和扫描接口。

### 规模

- 源文件: 37 个 .c 文件，1 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `opendir` | 打开目录流 |
| `fdopendir` | 从 fd 打开目录流 |
| `readdir` / `readdir64` | 读取目录项 |
| `readdir_r` | 可重入版本（已废弃） |
| `closedir` | 关闭目录流 |
| `rewinddir` | 重置目录流位置 |
| `seekdir` / `telldir` | 目录流定位 |
| `dirfd` | 获取目录流对应的 fd |
| `scandir` / `scandir64` | 扫描并排序目录 |
| `alphasort` | 字母排序比较函数 |
| `versionsort` | 版本号排序比较函数 |

### 使用模式

```c
DIR *dir = opendir("/path");
struct dirent *entry;
while ((entry = readdir(dir)) != NULL) {
    printf("%s\n", entry->d_name);
}
closedir(dir);
```

## 4. rt — POSIX 实时扩展

### 功能概述

`rt` 模块实现 POSIX.1b 实时扩展接口，包括异步 I/O、消息队列、
共享内存和高精度定时器。

### 规模

- 源文件: 77 个 .c 文件，3 个 .h 文件

### 功能分类

```
rt (librt)
├── 异步 I/O: aio_read, aio_write, aio_error, aio_return, aio_suspend
├── 消息队列: mq_open, mq_send, mq_receive, mq_notify, mq_close
├── 共享内存: shm_open, shm_unlink
└── 定时器: timer_create, timer_settime, timer_gettime, timer_delete
```

### 主要 API

| 类别 | 函数 | 说明 |
|------|------|------|
| AIO | `aio_read` / `aio_write` | 异步读写 |
| AIO | `aio_error` / `aio_return` | 查询异步操作状态/结果 |
| AIO | `aio_suspend` | 等待异步操作完成 |
| AIO | `aio_cancel` | 取消异步操作 |
| AIO | `lio_listio` | 批量异步操作 |
| MQ | `mq_open` / `mq_close` / `mq_unlink` | 消息队列生命周期 |
| MQ | `mq_send` / `mq_receive` | 消息收发 |
| MQ | `mq_notify` | 消息到达通知 |
| SHM | `shm_open` / `shm_unlink` | POSIX 共享内存 |
| Timer | `timer_create` / `timer_delete` | 创建/删除定时器 |
| Timer | `timer_settime` / `timer_gettime` | 设置/查询定时器 |

### 与 sysvipc 的区别

| 特性 | POSIX (rt) | System V (sysvipc) |
|------|-----------|-------------------|
| 命名 | 路径名 (`/name`) | 数字键值 (ftok) |
| 权限 | 文件系统权限 | IPC 权限位 |
| 接口风格 | fd-like | 专用 ID |
| 标准化 | POSIX.1b | POSIX (旧) |
| 推荐度 | ✅ 推荐 | ⚠️ 遗留 |

## 5. hurd / htl / mach — GNU Hurd 支持

### 功能概述

这些模块为 GNU Hurd 操作系统（基于 Mach 微内核）提供支持:

- **mach**: Mach 微内核接口封装
- **hurd**: Hurd 服务器协议和系统调用
- **htl**: Hurd Threads Library（Hurd 的线程库）

### 说明

- 仅在 GNU/Hurd 系统上使用
- Linux 系统不编译这些模块
- 提供与 Linux 版本功能等价的接口实现
- HTL 是 NPTL 在 Hurd 上的对应物

### 架构对比

```
Linux 系统:
  glibc → Linux 系统调用 → Linux 内核

Hurd 系统:
  glibc → Hurd RPC → Hurd 服务器 → Mach 微内核
```

## 7. nptl_db — 线程调试支持

### 功能概述

`nptl_db` 实现 `libthread_db.so`，为 GDB 等调试器提供线程感知调试能力。

### 规模

- 源文件: 42 个 .c 文件，2 个 .h 文件

### 提供的能力

- 枚举进程中的所有线程
- 读取线程特定数据（TSD）
- 获取线程寄存器状态
- 线程事件通知（创建、退出）

### 使用方式

调试器通过 `td_ta_*` 和 `td_thr_*` 系列函数访问:
- `td_ta_new`: 打开线程代理
- `td_ta_thr_iter`: 遍历线程
- `td_thr_getgregs`: 获取通用寄存器
- `td_thr_getfpregs`: 获取浮点寄存器
- `td_thr_event_enable`: 启用事件通知
