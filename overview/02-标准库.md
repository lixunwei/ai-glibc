# 标准库模块

标准库模块实现了 ISO C 标准定义的核心函数库。

---

## 1. stdlib — 标准工具库

### 功能概述

`stdlib` 模块实现了通用工具函数，包括数值转换、伪随机数生成、内存分配辅助、
进程控制、环境变量管理、排序/搜索等。

### 规模

- 源文件: 349 个 .c 文件，21 个 .h 文件

### 功能分类

```
stdlib
├── 数值转换: atoi, strtol, strtod, ...
├── 随机数: rand, random, arc4random, getrandom
├── 排序/搜索: qsort, bsearch
├── 进程控制: exit, abort, system, atexit
├── 环境变量: getenv, setenv, putenv
├── 临时文件: mkstemp, mkdtemp
└── 其他: abs, div, mbstowcs, realpath
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `atoi` / `atol` / `atoll` | 字符串转整数（简易版） |
| `strtol` / `strtoul` / `strtoll` | 字符串转整数（带错误检测） |
| `strtod` / `strtof` / `strtold` | 字符串转浮点数 |
| `rand` / `srand` | POSIX 伪随机数 |
| `random` / `srandom` | BSD 伪随机数 |
| `arc4random` / `arc4random_buf` | 密码学安全随机数 |
| `getrandom` | Linux 内核随机数接口 |
| `qsort` / `qsort_r` | 快速排序 |
| `bsearch` | 二分查找 |
| `exit` / `quick_exit` / `_Exit` | 进程退出 |
| `atexit` / `on_exit` / `at_quick_exit` | 注册退出处理函数 |
| `abort` | 异常终止 |
| `system` | 执行 shell 命令 |
| `getenv` / `setenv` / `unsetenv` | 环境变量操作 |
| `mkstemp` / `mkdtemp` | 创建临时文件/目录 |
| `realpath` | 解析真实路径 |

### 关键源文件

| 文件 | 功能 |
|------|------|
| strtol.c | 字符串到整数转换核心实现 |
| strtod_l.c | 字符串到浮点数转换 |
| setenv.c | 环境变量设置 |
| qsort.c | 排序算法实现 |
| exit.c | 进程退出及 atexit 调用 |
| random.c | 随机数生成器 |
| arc4random.c | ChaCha20 随机数 |

### 依赖关系

- 依赖 `string`（字符串操作）
- 依赖 `locale`（数值解析的本地化）
- 依赖 `nptl`（线程安全）
- 依赖 `math`（浮点数解析）

## 2. string — 字符串与内存操作

### 功能概述

`string` 模块提供字节/字符串操作函数，包括复制、比较、搜索、连接等，
以及 `argz`/`envz` 辅助接口和错误消息函数。

### 规模

- 源文件: 163 个 .c 文件，10 个 .h 文件

### 功能分类

```
string
├── 内存操作: memcpy, memmove, memset, memcmp, memchr
├── 字符串操作: strcpy, strcat, strcmp, strlen, strdup
├── 字符串搜索: strstr, strchr, strrchr, memmem
├── 本地化: strcoll, strxfrm
├── 错误消息: strerror, strerror_r, strsignal
├── 令牌化: strtok, strsep
└── 辅助: argz_*, envz_*, explicit_bzero
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `memcpy` / `memmove` | 内存复制（不重叠/可重叠） |
| `memset` | 内存填充 |
| `memcmp` | 内存比较 |
| `memchr` / `memrchr` | 内存中查找字节 |
| `memmem` | 内存中查找子串 |
| `strcpy` / `strncpy` | 字符串复制 |
| `strcat` / `strncat` | 字符串连接 |
| `strcmp` / `strncmp` | 字符串比较 |
| `strcasecmp` | 忽略大小写比较 |
| `strlen` / `strnlen` | 字符串长度 |
| `strchr` / `strrchr` | 查找字符 |
| `strstr` | 查找子串（Two-Way 算法） |
| `strdup` / `strndup` | 复制字符串（分配新内存） |
| `strerror` / `strerror_r` | 错误码转描述文本 |
| `strcoll` / `strxfrm` | 本地化排序/变换 |
| `strtok` / `strsep` | 字符串分割 |
| `explicit_bzero` | 安全清零（不被优化掉） |

### 性能优化

- 许多函数有 **架构特定优化版本**（在 `sysdeps/` 下），如:
  - x86_64 的 SSE/AVX `memcpy`、`strlen`
  - aarch64 的 NEON `memcmp`
- `strstr` 使用 **Two-Way 字符串搜索算法**
- `memcpy` 使用 **word-copy** 优化

### 依赖关系

- 依赖 `locale`（`strcoll`/`strxfrm`）
- 依赖 `malloc`（`strdup`/`strndup`）
- 几乎被所有其他模块依赖

## 3. math — 数学库 (libm)

### 功能概述

`math` 模块实现 ISO C 数学函数库 (libm)，提供三角函数、指数/对数、
浮点分类、特殊函数等，严格遵循 IEEE-754 标准。

### 规模

- 源文件: 288 个 .c 文件，49 个 .h 文件

### 功能分类

```
math (libm)
├── 三角函数: sin, cos, tan, asin, acos, atan
├── 双曲函数: sinh, cosh, tanh, asinh, acosh, atanh
├── 指数/对数: exp, log, log10, log2, pow, exp2
├── 浮点操作: fabs, floor, ceil, trunc, round, fmod
├── 特殊函数: tgamma, lgamma, erf, erfc, j0, j1, jn
├── 复数函数: csin, ccos, cexp, clog, cpow, ...
├── 浮点环境: fesetround, fegetexcept, ...
└── 类型变体: float/double/long double/_Float128
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `sin` / `cos` / `tan` | 三角函数 |
| `asin` / `acos` / `atan` / `atan2` | 反三角函数 |
| `exp` / `exp2` / `expm1` | 指数函数 |
| `log` / `log10` / `log2` / `log1p` | 对数函数 |
| `pow` / `sqrt` / `cbrt` | 幂/根函数 |
| `fabs` / `hypot` | 绝对值/斜边 |
| `floor` / `ceil` / `trunc` / `round` | 取整函数 |
| `fmod` / `remainder` | 取模 |
| `tgamma` / `lgamma` | Gamma 函数 |
| `erf` / `erfc` | 误差函数 |
| `fesetround` / `fegetenv` | 浮点环境控制 |
| `fpclassify` / `isnan` / `isinf` | 浮点分类 |

### 实现模式

- **模板机制**: 使用 `w_*_template.c` 和 `s_*_template.c` 为不同浮点类型生成代码
- **IEEE-754 异常处理**: 通过 `fenv` 接口报告 INVALID、OVERFLOW 等异常
- **版本符号**: 支持多个 glibc 版本的 ABI 兼容
- **架构优化**: x86 使用 FPU/SSE 指令，aarch64 使用 NEON

### 关键源文件

| 文件 | 功能 |
|------|------|
| math.h | 主头文件 |
| complex.h | 复数类型和函数 |
| w_exp.c / w_log.c | 包装函数（错误处理） |
| s_sin.c / s_cos.c | 核心实现 |
| e_pow.c / e_exp.c | 核心实现（内部） |
| math_private.h | 内部浮点操作宏 |

### 依赖关系

- 依赖 `fenv`（浮点环境）
- 依赖编译器内建函数
- 依赖架构特定 FPU 支持（`sysdeps/`）
- 独立为 `libm.so`

## 4. stdio-common — 格式化 I/O

### 功能概述

`stdio-common` 模块实现了 `printf`/`scanf` 系列格式化输入输出函数，
是 glibc 中测试最密集的模块之一。

### 规模

- 源文件: 561 个 .c 文件，37 个 .h 文件

### 功能分类

```
stdio-common
├── 格式化输出: printf, fprintf, sprintf, snprintf, asprintf, dprintf
├── 格式化输入: scanf, fscanf, sscanf
├── 行输入: getline, getdelim
├── 锁操作: flockfile, funlockfile
├── 终端: ctermid
└── 辅助: printf 注册格式、扩展
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `printf` / `fprintf` / `dprintf` | 格式化输出到 stdout/文件/fd |
| `sprintf` / `snprintf` | 格式化输出到缓冲区 |
| `asprintf` | 自动分配缓冲区的格式化输出 |
| `vprintf` / `vfprintf` / `vsprintf` | va_list 版本 |
| `scanf` / `fscanf` / `sscanf` | 格式化输入 |
| `getline` / `getdelim` | 动态行读取 |
| `flockfile` / `funlockfile` | 流锁定 |
| `register_printf_specifier` | 注册自定义格式说明符 |

### 实现特点

- 支持 C99/C23 格式说明符（`%a`, `%b`, `%wN` 等）
- 支持 POSIX 扩展（`%n$` 位置参数）
- long double 和 `_Float128` 特化路径
- 支持本地化（千位分隔符、小数点等）

### 依赖关系

- 依赖 `libio`（底层流操作）
- 依赖 `locale`（本地化数值格式）
- 依赖 `math`（浮点数输出）
- 依赖 `string`（字符串操作）
- 依赖 `malloc`（`asprintf` 内存分配）
