## 1. 库文件构成与边界

glibc 2.34+ 将 libpthread/libdl/librt 合并入 libc.so，当前产物结构：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         应用程序 (a.out / .so)                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌──────────────────────────────────────────────────────────────────┐   │
│  │                    libc.so.6 (主库, ~2MB)                        │   │
│  │                                                                  │   │
│  │  ┌────────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌────────┐ ┌──────────┐ │   │
│  │  │ string │ │malloc│ │ nptl │ │signal│ │  libio │ │stdio-com │ │   │
│  │  │ 字符串 │ │ 分配 │ │ 线程 │ │ 信号 │ │ 流引擎 │ │ 格式化IO │ │   │
│  │  └────────┘ └──────┘ └──────┘ └──────┘ └────────┘ └──────────┘ │   │
│  │  ┌────────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌────────┐ ┌──────────┐ │   │
│  │  │   io   │ │locale│ │ time │ │ math │ │  inet  │ │  socket  │ │   │
│  │  │ 文件IO │ │国际化│ │ 时间 │ │ 数学 │ │  网络  │ │  套接字  │ │   │
│  │  └────────┘ └──────┘ └──────┘ └──────┘ └────────┘ └──────────┘ │   │
│  │  ┌────────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌────────┐              │   │
│  │  │  nss   │ │resolv│ │ dlfcn│ │dirent│ │ wcsmbs │    ...       │   │
│  │  │名称服务│ │ DNS  │ │dl接口│ │ 目录 │ │宽字符  │              │   │
│  │  └────────┘ └──────┘ └──────┘ └──────┘ └────────┘              │   │
│  └──────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌───────────────┐  ┌──────────────┐  ┌──────────────────────────────┐  │
│  │ ld-linux-      │  │ libm.so.6    │  │ libnss_*.so.2               │  │
│  │ aarch64.so.1   │  │ 数学库       │  │ NSS 后端模块                │  │
│  │ (动态链接器)   │  │ (libmvec含内)│  │ (files/dns/compat/...)      │  │
│  └───────────────┘  └──────────────┘  └──────────────────────────────┘  │
│                                                                         │
│  ┌───────────────┐  ┌──────────────┐  ┌──────────────────────────────┐  │
│  │ libresolv.so.2│  │ libthread_   │  │ libpthread.so.0 (空壳兼容)  │  │
│  │ DNS 解析器    │  │ db.so.1      │  │ libdl.so.2      (空壳兼容)  │  │
│  │              │  │ 调试支持      │  │ librt.so.1      (空壳兼容)  │  │
│  └───────────────┘  └──────────────┘  └──────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       Linux Kernel (syscall 接口)                       │
└─────────────────────────────────────────────────────────────────────────┘
```

**关键边界：**
- `ld.so` 是独立的 ELF 可执行文件，有自己的 malloc（简易版）和 TLS 管理
- `libc.so` 包含绝大部分功能模块，通过 `_dl_call_libc_early_init` 被 ld.so 激活
- 空壳兼容库仅转发符号到 libc.so，支持旧版链接脚本

**依赖方向**：上层依赖下层，同层组件可互相依赖（需特殊处理循环）。

## 11. 循环依赖与解决策略

```
   ┌───────────────────────────────────────────────────────────────────┐
   │               glibc 三大循环依赖                                   │
   └───────────────────────────────────────────────────────────────────┘

   ① malloc ◄────────────────────────► nptl
     │                                    │
     │ malloc 需要锁 (mutex)              │ nptl 需要 mmap 分配栈
     │ arena->mutex                       │ allocate_thread_stack()
     │                                    │
     └── 解决: nptl 用 mmap 不用 malloc ──┘

               __libc_single_threaded 标志

   ② elf ◄──────────────────────────► nptl
     │                                    │
     │ elf 需要 TLS 支持                  │ TLS 依赖 elf 加载
     │ _dl_allocate_tls()                 │ PT_TLS 段解析
     │                                    │
     └── 解决: TLS 初始化代码静态链接 ────┘
               到 ld.so 内部
               ld.so 有独立的 TLS 初始化路径

   ③ libio ◄────────────────────────► malloc
     │                                    │
     │ printf 需要 malloc                 │ malloc 错误报告需要 printf
     │ 格式化缓冲区分配                   │ __libc_message()
     │                                    │
     └── 解决: malloc 错误路径使用 ───────┘

   ┌───────────────────────────────────────────────────────────────────┐
   │               初始化阶段的特殊处理                                 │
   │                                                                   │
   │  __libc_single_threaded = 1 (初始值)                              │
   │  │                                                                │
   │  │  malloc: 跳过锁操作                                            │
   │  │  libio:  跳过锁操作                                            │
   │  │  ctype:  直接使用全局 locale                                   │
   │  │                                                                │
   │  pthread_create() 首次调用时:                                     │
   │  │  __libc_single_threaded = 0                                    │

       │    ├─ YES ──► vDSO 函数 (用户态执行, ~20ns)
       │    │          ├─ 读取内核共享时间页面
       │    │          └─ 计算当前时间, 直接返回
       │    │
       │    └─ NO ───► syscall(__NR_clock_gettime) (~200ns)
       │               陷入内核, 上下文切换
       │
       └─► 返回结果
```
