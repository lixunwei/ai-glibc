# 国际化模块

国际化模块使 glibc 程序能够适应不同语言、字符集和文化习惯。

---

## 1. locale — 本地化运行时

### 功能概述

`locale` 模块管理程序的本地化设置，控制数字格式、日期格式、排序规则、
货币符号等与地域相关的行为。

### 规模

- 源文件: 49 个 .c 文件，14 个 .h 文件

### 核心架构

```
┌─────────────────────────────────────────────┐
│  应用程序                                    │
│  setlocale("LC_ALL", "zh_CN.UTF-8")         │
├─────────────────────────────────────────────┤
│  Locale 对象管理                             │
│  (newlocale / uselocale / freelocale)        │
├─────────────────────────────────────────────┤
│  Locale 数据加载                             │
│  ┌──────────────────┬─────────────────┐     │
│  │ 归档文件加载      │ 单独文件加载     │     │
│  │ (locale-archive) │ (/usr/lib/locale)│     │
│  └──────────────────┴─────────────────┘     │
├─────────────────────────────────────────────┤
│  LC_CTYPE │ LC_COLLATE │ LC_TIME │ ...      │
└─────────────────────────────────────────────┘
```

### Locale 分类

| 分类 | 控制内容 |
|------|----------|
| `LC_CTYPE` | 字符分类和大小写转换 |
| `LC_COLLATE` | 字符串排序规则 |
| `LC_TIME` | 日期时间格式 |
| `LC_NUMERIC` | 数字格式（小数点、千位分隔符） |
| `LC_MONETARY` | 货币格式 |
| `LC_MESSAGES` | 消息语言 |
| `LC_PAPER` | 纸张大小 |
| `LC_NAME` | 姓名格式 |
| `LC_ADDRESS` | 地址格式 |
| `LC_TELEPHONE` | 电话号码格式 |
| `LC_MEASUREMENT` | 度量衡单位 |

### 主要 API

| 函数 | 说明 |
|------|------|
| `setlocale` | 设置/查询全局 locale |
| `localeconv` | 获取数值/货币格式信息 |
| `newlocale` | 创建 locale 对象 |
| `duplocale` | 复制 locale 对象 |
| `freelocale` | 释放 locale 对象 |
| `uselocale` | 设置线程 locale |
| `nl_langinfo` / `nl_langinfo_l` | 查询 locale 信息项 |

### 关键源文件

| 文件 | 功能 |
|------|------|
| setlocale.c | 全局 locale 设置 |
| newlocale.c / uselocale.c | per-thread locale |
| loadlocale.c | locale 数据加载 |
| loadarchive.c | locale 归档加载 |
| findlocale.c | locale 查找逻辑 |

## 2. iconv / iconvdata — 字符集转换

### 功能概述

`iconv` 模块提供字符编码转换框架，`iconvdata` 包含具体的编码转换实现模块。
支持数百种字符编码之间的相互转换。

### 规模

- iconv: 36 个 .c 文件，8 个 .h 文件
- iconvdata: 282 个 .c 文件，77 个 .h 文件

### 架构

```
┌─────────────────────────────────────────────┐
│  iconv_open("UTF-8", "GBK")                 │
├─────────────────────────────────────────────┤
│  gconv 框架 (派发/链式转换)                   │
│  gconv_open → gconv_db → gconv_cache        │
├─────────────────────────────────────────────┤
│  转换模块 (iconvdata/*.so)                   │
│  ┌──────┬──────┬──────┬──────┬──────┐      │
│  │UTF-8 │GBK   │EUC-JP│BIG5  │ISO-*│ ...   │
│  └──────┴──────┴──────┴──────┴──────┘      │
└─────────────────────────────────────────────┘
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `iconv_open` | 打开转换描述符 |
| `iconv` | 执行字符转换 |
| `iconv_close` | 关闭转换描述符 |

### 支持的主要编码

- **Unicode**: UTF-8, UTF-16, UTF-32, UTF-7
- **中文**: GBK, GB18030, GB2312, BIG5, HZ
- **日文**: EUC-JP, Shift_JIS, ISO-2022-JP
- **韩文**: EUC-KR, ISO-2022-KR
- **欧洲**: ISO-8859-*, Windows-125*, KOI8-R
- **通用**: ASCII, EBCDIC 变体

### 内部机制

- gconv 框架支持链式转换（通过 UTF-8 中间编码）
- 转换模块按需 `dlopen` 加载
- 缓存机制（`gconv-modules.cache`）加速模块查找
- 支持转写（transliteration）

## 3. intl — gettext 国际化

### 功能概述

`intl` 模块实现 GNU gettext 消息翻译框架，使程序能够根据用户的语言设置
显示对应翻译的文本。

### 规模

- 源文件: 26 个 .c 文件，7 个 .h 文件

### 工作流程

```
程序代码:
  printf(gettext("Hello, world!\n"));

运行时查找:
  1. 确定当前 LC_MESSAGES locale
  2. 在 textdomain 指定的目录中查找 .mo 文件
  3. 用哈希表查找翻译字符串
  4. 返回翻译结果（或原始字符串）
```

### 主要 API

| 函数 | 说明 |
|------|------|
| `gettext` | 获取翻译文本 |
| `dgettext` | 指定域的翻译 |
| `dcgettext` | 指定域和分类的翻译 |
| `ngettext` | 带复数形式的翻译 |
| `dngettext` | 指定域的复数翻译 |
| `textdomain` | 设置默认文本域 |
| `bindtextdomain` | 绑定域到目录 |
| `bind_textdomain_codeset` | 设置输出编码 |

### 消息目录布局

```
/usr/share/locale/
├── zh_CN/
│   └── LC_MESSAGES/
│       └── coreutils.mo    ← 二进制消息目录
├── ja/
│   └── LC_MESSAGES/
│       └── coreutils.mo
└── ...
```

## 4. wcsmbs — 宽字符与多字节字符串

### 功能概述

`wcsmbs` 模块提供宽字符（`wchar_t`）和多字节字符串之间的转换函数，
以及宽字符版本的字符串操作函数。

### 规模

- 源文件: 147 个 .c 文件，5 个 .h 文件

### 主要 API

| 类别 | 函数 | 说明 |
|------|------|------|
| 转换 | `mbrtowc` / `wcrtomb` | 单字符转换（可重入） |
| 转换 | `mbsrtowcs` / `wcsrtombs` | 字符串转换 |
| 转换 | `btowc` / `wctob` | 单字节快速转换 |
| C11 | `mbrtoc16` / `c16rtomb` | char16_t 转换 |
| C11 | `mbrtoc32` / `c32rtomb` | char32_t 转换 |
| 字符串 | `wcslen` / `wcscpy` / `wcscat` | 宽字符串操作 |
| 字符串 | `wcscmp` / `wcsncmp` / `wcscoll` | 宽字符串比较 |
| 数值 | `wcstol` / `wcstod` | 宽字符串转数值 |
| 搜索 | `wcschr` / `wcsstr` / `wcstok` | 宽字符串搜索 |

## 5. ctype / wctype — 字符分类

### 功能概述

`ctype` 提供 ASCII/locale 字符分类和转换（基于查表），
`wctype` 提供对应的宽字符版本。

### 规模

- ctype: 12 个 .c 文件，1 个 .h 文件
- wctype: 13 个 .c 文件，2 个 .h 文件

### 主要 API

| 函数 | 说明 |
|------|------|
| `isalpha` / `iswalpha` | 是否字母 |
| `isdigit` / `iswdigit` | 是否数字 |
| `isalnum` / `iswalnum` | 是否字母或数字 |
| `isspace` / `iswspace` | 是否空白 |
| `isupper` / `islower` | 是否大/小写 |
| `ispunct` / `iswpunct` | 是否标点 |
| `isprint` / `iswprint` | 是否可打印 |
| `toupper` / `tolower` | 大小写转换 |
| `towupper` / `towlower` | 宽字符大小写转换 |
| `wctype` / `iswctype` | 通用分类查询 |
| `wctrans` / `towctrans` | 通用转换 |

### 实现特点

- `ctype` 使用 **查表法**（256 条目数组），极快
- locale 变体（`*_l`）支持线程安全的 per-locale 分类
- `wctype` 使用 Unicode 属性数据

## 6. catgets — 消息目录（X/Open）

### 功能概述

`catgets` 实现 X/Open 消息目录接口，是 `gettext` 的旧式替代方案。

### 主要 API

| 函数 | 说明 |
|------|------|
| `catopen` | 打开消息目录 |
| `catgets` | 获取消息文本 |
| `catclose` | 关闭消息目录 |

### 附带工具

- `gencat`: 编译消息目录源文件为二进制格式
