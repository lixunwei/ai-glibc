# 信号掩码与等待

## 一、sigprocmask / pthread_sigmask

### 调用关系

```
sigprocmask(how, set, oset)          [POSIX 进程级 API]
  → __sigprocmask(how, set, oset)    [sysdeps/unix/sysv/linux/sigprocmask.c:21-32]
    → __pthread_sigmask(how, set, oset)  [nptl/pthread_sigmask.c:23-46]
      │  过滤 SIGCANCEL/SIGSETXID
      → INTERNAL_SYSCALL_CALL(rt_sigprocmask, how, newmask, oldmask, __NSIG_BYTES)

pthread_sigmask(how, set, oset)      [POSIX 线程级 API]
  → __pthread_sigmask(how, set, oset)  [同上]
```

在 Linux/NPTL 上，`sigprocmask` 和 `pthread_sigmask` 最终调用同一个函数。

### __sigprocmask — Linux 包装

**源文件**: `sysdeps/unix/sysv/linux/sigprocmask.c:21-32`

```c
int __sigprocmask(int how, const sigset_t *set, sigset_t *oset)
{
    int result = __pthread_sigmask(how, set, oset);
    if (result) {
        __set_errno(result);
        return -1;
    }
    return 0;
}
```

区别：`sigprocmask` 返回 -1/errno，`pthread_sigmask` 直接返回错误码。

### __pthread_sigmask — 核心实现

**源文件**: `nptl/pthread_sigmask.c:23-46`

```c
int __pthread_sigmask(int how, const sigset_t *newmask, sigset_t *oldmask)
{
    sigset_t local_newmask;

    // 关键: 保护内部信号不被阻塞
    if (newmask != NULL
        && (__glibc_unlikely(__sigismember(newmask, SIGCANCEL))
            || __glibc_unlikely(__sigismember(newmask, SIGSETXID))))
    {
        local_newmask = *newmask;
        clear_internal_signals(&local_newmask);  // 移除 SIGCANCEL + SIGSETXID
        newmask = &local_newmask;
    }

    // rt_sigprocmask 系统调用
    int result = INTERNAL_SYSCALL_CALL(rt_sigprocmask, how, newmask,
                                       oldmask, __NSIG_BYTES);

    return (INTERNAL_SYSCALL_ERROR_P(result)
            ? INTERNAL_SYSCALL_ERRNO(result)
            : 0);
}
```

**设计要点**:
- 即使用户请求 `SIG_BLOCK` 阻塞所有信号，SIGCANCEL 和 SIGSETXID 也不会被阻塞
- 这确保了 `pthread_cancel()` 和 `setuid()` 全线程同步始终能工作

### how 参数

| 值 | 说明 |
|-----|------|
| `SIG_BLOCK` | 将 set 中的信号添加到当前掩码 |
| `SIG_UNBLOCK` | 从当前掩码中移除 set 中的信号 |
| `SIG_SETMASK` | 用 set 替换整个信号掩码 |

## 二、sigsuspend — 原子替换掩码并等待

**源文件**: `sysdeps/unix/sysv/linux/sigsuspend.c:21-31`

```c
int __sigsuspend(const sigset_t *set)
{
    return SYSCALL_CANCEL(rt_sigsuspend, set, __NSIG_BYTES);
}
```

**语义**:
```
sigsuspend(mask):
  1. 原子地: 保存当前信号掩码 → 设为 mask → 挂起
  2. 等待一个未被 mask 阻塞的信号到达
  3. 执行信号处理器
  4. 恢复原始信号掩码
  5. 返回 -1 (EINTR)
```

**用途**: 实现可靠的信号等待，避免 "先解除阻塞再 pause()" 的竞态条件。

**取消点**: 使用 `SYSCALL_CANCEL` 包装，是 POSIX 取消点。

## 四、sigwait 系列 — 同步等待信号

### sigwait

**源文件**: `sysdeps/unix/sysv/linux/sigwait.c:22-39`

```c
int __sigwait(const sigset_t *set, int *sig)
{
    siginfo_t si;
    int ret;
    
    // 循环直到成功（忽略 EINTR）
    do
        ret = __sigtimedwait(set, &si, NULL);
    while (ret < 0 && errno == EINTR);
    
    if (ret < 0)
        return errno;
    *sig = si.si_signo;
    return 0;
}
```

**特点**: 在 EINTR 上自动重试（不同于 sigtimedwait）。

### sigwaitinfo

**源文件**: `sysdeps/unix/sysv/linux/sigwaitinfo.c:21-30`

```c
int __sigwaitinfo(const sigset_t *set, siginfo_t *info)
{
    return __sigtimedwait(set, info, NULL);  // timeout=NULL → 无限等待
}
```

### sigtimedwait

**源文件**: `sysdeps/unix/sysv/linux/sigtimedwait.c:22-84`

```c
int __sigtimedwait64(const sigset_t *set, siginfo_t *info,
                     const struct __timespec64 *timeout)
{
#ifdef __ASSUME_TIME64_SYSCALLS
    // 现代系统直接使用 time64 系统调用
    result = SYSCALL_CANCEL(rt_sigtimedwait_time64, set, info,
                            timeout, __NSIG_BYTES);
#else
    // 旧系统: 根据 timeout 是否超出 int32 范围选择 syscall
    if (need_time64)
        result = SYSCALL_CANCEL(rt_sigtimedwait_time64, ...);  // 溢出则 EOVERFLOW
    else
        result = SYSCALL_CANCEL(rt_sigtimedwait, ...);         // 32 位回退
#endif
    
    // SI_TKILL → SI_USER 归一化
    if (result != -1 && info != NULL && info->si_code == SI_TKILL)
        info->si_code = SI_USER;
    
    return result;
}
```

**设计细节**:
- 使用 `SYSCALL_CANCEL` 宏 → 是取消点
- `SI_TKILL` 到 `SI_USER` 的转换是 glibc 的兼容行为
- time64 优先策略确保 2038 年后正确

## 五、信号掩码与线程模型

### 每线程信号掩码

Linux 信号掩码是线程级的（不是进程级）：

```
进程 P
├── 线程 T1: mask = {SIGINT, SIGUSR1}
├── 线程 T2: mask = {SIGTERM}
└── 线程 T3: mask = {}

信号投递规则:
  - 进程级信号（kill）: 选择一个未阻塞的线程投递
  - 线程级信号（tgkill）: 投递到指定线程
```

### 子线程继承掩码

```c
pthread_create() 时:
  新线程继承创建者的信号掩码
  
  典型模式（主线程处理信号）:
    sigset_t set;
    sigfillset(&set);
    pthread_sigmask(SIG_BLOCK, &set, NULL);  // 阻塞所有信号
    pthread_create(&tid, NULL, worker, NULL); // worker 继承阻塞
    sigwait(&set, &sig);                      // 主线程同步等待
```

### 线程创建时的内部信号处理

**源文件**: `nptl/pthread_create.c:78-92`（`late_init` 一次性初始化）

```
late_init() — 首个线程创建时调用一次:
  1. 安装 SIGSETXID 处理器 (SA_ONSTACK | SA_SIGINFO | SA_RESTART)
  2. 解除 SIGCANCEL/SIGSETXID 的阻塞

start_thread() (行 338-454) 中:
  internal_signal_restore_set(&pd->sigmask)  // 行 438, 恢复信号掩码
  → 开始执行用户函数                          // 行 442-454
```
