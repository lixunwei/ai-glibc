# 信号基础与数据结构

## 一、sigset_t — 信号集

### 类型定义

**源文件**: `signal/bits/types/sigset_t.h`

```c
typedef __sigset_t sigset_t;
```

底层实现（`bits/types/__sigset_t.h`）:
```c
typedef struct {
    unsigned long int __val[_SIGSET_NWORDS];  // _SIGSET_NWORDS = 1024/(8*sizeof(long))
} __sigset_t;
```

在 64 位系统上: `_SIGSET_NWORDS = 16`，总计 128 字节（1024 位），但内核实际只使用前 64 位（`_NSIG = 65`）。

### 内核接口大小

**源文件**: `sysdeps/unix/sysv/linux/sigsetops.h:37-47`

```c
// 内核只处理 __NSIG_WORDS 个 word，不是整个 sigset_t
#define __NSIG_WORDS (ALIGN_UP((_NSIG - 1), ULONG_WIDTH) / ULONG_WIDTH)
// 64位系统: __NSIG_WORDS = 1 (64个信号 / 64位 = 1 word)

// syscall 传入的字节大小
#define __NSIG_BYTES (__NSIG_WORDS * (ULONG_WIDTH / UCHAR_WIDTH))
// 64位系统: __NSIG_BYTES = 8
```

### 位域操作

**源文件**: `sysdeps/unix/sysv/linux/sigsetops.h:26-113`

```c
// 信号编号 → 位掩码（信号从 1 开始编号）
#define __sigmask(sig)  (1UL << (((sig) - 1) % ULONG_WIDTH))

// 信号编号 → 字索引
static inline int __sigword(int sig) {
    return (sig - 1) / ULONG_WIDTH;
}

// 清空信号集
static inline void __sigemptyset(sigset_t *set) {
    int cnt = __NSIG_WORDS;
    while (--cnt >= 0) set->__val[cnt] = 0;
}

// 填满信号集
static inline void __sigfillset(sigset_t *set) {
    int cnt = __NSIG_WORDS;
    while (--cnt >= 0) set->__val[cnt] = ~0UL;
}

// 测试某信号是否在集合中
static inline int __sigismember(const sigset_t *set, int sig) {
    unsigned long int mask = __sigmask(sig);
    int word = __sigword(sig);
    return set->__val[word] & mask ? 1 : 0;
}

// 添加信号到集合
static inline void __sigaddset(sigset_t *set, int sig) {
    unsigned long int mask = __sigmask(sig);
    int word = __sigword(sig);
    set->__val[word] |= mask;
}

// 从集合中删除信号
static inline void __sigdelset(sigset_t *set, int sig) {
    unsigned long int mask = __sigmask(sig);
    int word = __sigword(sig);
    set->__val[word] &= ~mask;
}
```

### 位计算示例

```
信号 SIGTERM (15):
  __sigword(15) = (15-1) / 64 = 0    → 第 0 个 word
  __sigmask(15) = 1UL << ((15-1) % 64) = 1UL << 14 = 0x4000

信号 SIGRTMIN (32):
  __sigword(32) = (32-1) / 64 = 0    → 仍在第 0 个 word
  __sigmask(32) = 1UL << 31 = 0x80000000

信号 SIGRTMIN+1 (33):
  __sigword(33) = (33-1) / 64 = 0    → 仍在第 0 个 word
  __sigmask(33) = 1UL << 32 = 0x100000000
```

## 二、struct sigaction

### 用户态结构

**源文件**: `sysdeps/unix/sysv/linux/bits/sigaction.h:26-53`

```c
struct sigaction {
    union {
        __sighandler_t sa_handler;     // SIG_DFL / SIG_IGN / 处理函数
        void (*sa_sigaction)(int, siginfo_t *, void *);  // SA_SIGINFO 模式
    } __sigaction_handler;
    
    __sigset_t sa_mask;      // 处理期间阻塞的信号集
    int sa_flags;            // 行为标志
    void (*sa_restorer)(void);  // 信号返回跳板（glibc 自动填写）
};

#define sa_handler   __sigaction_handler.sa_handler
#define sa_sigaction __sigaction_handler.sa_sigaction
```

### sa_flags 标志

| 标志 | 值 | 说明 |
|------|-----|------|
| `SA_NOCLDSTOP` | 0x00000001 | 子进程停止时不发 SIGCHLD |
| `SA_NOCLDWAIT` | 0x00000002 | 子进程终止后不产生僵尸 |
| `SA_SIGINFO` | 0x00000004 | 使用三参数处理函数 |
| `SA_ONSTACK` | 0x08000000 | 在备用信号栈上执行 |
| `SA_RESTART` | 0x10000000 | 被中断的系统调用自动重启 |
| `SA_NODEFER` | 0x40000000 | 不自动阻塞当前信号 |
| `SA_RESETHAND` | 0x80000000 | 执行后恢复为 SIG_DFL |
| `SA_RESTORER` | 0x04000000 | 内部标志：sa_restorer 有效 |

### 内核态结构

**源文件**: `sysdeps/unix/sysv/linux/kernel_sigaction.h:8-19`

```c
struct kernel_sigaction {
    __sighandler_t k_sa_handler;
    unsigned long sa_flags;
    void (*sa_restorer)(void);     // 仅当 SA_RESTORER 设置时有效
    sigset_t sa_mask;              // 内核只读取 __NSIG_BYTES
};
```

用户态和内核态结构的区别：
- 字段顺序不同（内核 restorer 在 mask 前面）
- 大小不同（用户态 sigset_t 128字节 vs 内核只用 8 字节）
- flags 类型不同（用户态 int vs 内核 unsigned long）

```c

```

## 五、内部信号保护

**源文件**: `sysdeps/unix/sysv/linux/internal-signals.h:30-54`

```c
#define SIGCANCEL  __SIGRTMIN        // 32: 线程取消
#define SIGTIMER   SIGCANCEL         // 复用取消信号做定时器
#define SIGSETXID  (__SIGRTMIN + 1)  // 33: setuid 同步
#define RESERVED_SIGRT  2            // 保留 2 个实时信号

// 判断是否为内部信号
static inline bool is_internal_signal(int sig) {
    return (sig == SIGCANCEL) || (sig == SIGSETXID);
}

// 从信号集中移除内部信号
static inline void clear_internal_signals(sigset_t *set) {
    __sigdelset(set, SIGCANCEL);
    __sigdelset(set, SIGSETXID);
}
```
