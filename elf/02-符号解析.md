### Elf64_Sym 结构

```c
typedef struct {
    Elf64_Word    st_name;    // 符号名（字符串表偏移）
```

### 符号绑定类型

**源文件**: `elf/elf.h:572-607`

| 绑定 | 值 | 说明 |
|------|-----|------|
| `STB_LOCAL` | 0 | 文件内局部，不参与链接 |
| `STB_GLOBAL` | 1 | 全局可见，多重定义报错 |
| `STB_WEAK` | 2 | 弱符号，可被强符号覆盖 |

| 类型 | 值 | 说明 |

## 二、哈希表

### Classic ELF Hash (DT_HASH)

**源文件**: `sysdeps/generic/dl-hash.h:23-73`

```c
unsigned long _dl_elf_hash(const char *name) {
    unsigned long h = 0, g;
    while (*name) {
        h = (h << 4) + *name++;
        g = h & 0xf0000000;
        if (g) h ^= g >> 24;
        h &= ~g;
    }
    return h;
}
```

**结构**:
```
DT_HASH 指向:
┌──────────┬──────────┬──────────────┬──────────────┐
│ nbucket  │ nchain   │ bucket[...]  │ chain[...]   │
└──────────┴──────────┴──────────────┴──────────────┘

查找: bucket[hash % nbucket] → chain 遍历直到 STN_UNDEF
```

### GNU Hash (DT_GNU_HASH)

**源文件**: `sysdeps/generic/dl-new-hash.h:26-107`

```c
unsigned int _dl_new_hash(const char *s) {
    unsigned int h = 5381;
    for (unsigned char c = *s; c != '\0'; c = *++s)
        h = h * 33 + c;
    return h;
}
```

**结构**:
```
DT_GNU_HASH 指向:
┌──────────┬────────────┬───────────┬──────────────┬──────────────┐
│ nbuckets │ symoffset  │ bloom_size│ bloom_shift  │              │
├──────────┴────────────┴───────────┴──────────────┤              │
│           Bloom Filter (bitmask[bloom_size])       │              │
├───────────────────────────────────────────────────┤              │
│           Buckets[nbuckets]                        │              │
├───────────────────────────────────────────────────┤              │
│           Chains[] (hash values with stop bit)     │              │
└───────────────────────────────────────────────────┘
```

### GNU Hash 查找算法

**源文件**: `elf/dl-lookup.c:400-441`

```
gnu_hash_lookup(map, name, hash):
  // 1. Bloom Filter 快速排除
  bitmask_word = map->l_gnu_bitmask[(hash / __ELF_NATIVE_CLASS) & idxbits]
  bit1 = hash % __ELF_NATIVE_CLASS
  bit2 = (hash >> bloom_shift) % __ELF_NATIVE_CLASS
  if !(bitmask_word & (1 << bit1) & (1 << bit2)):
    return NOT_FOUND    // 一定不存在

  // 2. Bucket 定位链起始
  bucket_idx = hash % nbuckets
  symidx = buckets[bucket_idx]
  if symidx == 0: return NOT_FOUND

  // 3. Chain 遍历（比较 hash 值 + 名称）
  hashval = chains[symidx - symoffset]
  while true:
    if (hashval ^ hash) >> 1 == 0:  // 高 31 位匹配
      sym = symtab[symidx]
      if strcmp(strtab + sym->st_name, name) == 0:
        return sym    // 找到！
    if hashval & 1:   // stop bit
      break
    symidx++
    hashval = chains[symidx - symoffset]
  return NOT_FOUND
```

**性能优势**:
- Bloom filter: 单次内存访问排除 ~97% 不存在的符号
- 只存储 `STB_GLOBAL`/`STB_WEAK` 符号（跳过 LOCAL）
- Hash 值内联在 chain 中，避免 strcmp 直到高位匹配

## 三、符号查找算法

### 入口：_dl_lookup_symbol_x

**源文件**: `elf/dl-lookup.c:761-887`

```
_dl_lookup_symbol_x(undef_name, undef_map, ref, symbol_scope,
                     version, type_class, flags, skip_map):
  
  hash = _dl_new_hash(undef_name)     // GNU hash
  old_hash = 0xFFFFFFFF               // 延迟计算 ELF hash
  
  current_value = { sym=NULL, map=NULL }
  
  // 遍历搜索作用域
  for scope in symbol_scope[]:
    result = do_lookup_x(undef_name, hash, &old_hash,
                         ref, &current_value, scope,
                         version, type_class, skip_map)
    if result != 0:
      break
  
  // 检查结果
  if current_value.sym == NULL:
    if ref->st_info.bind != STB_WEAK:
      报错: undefined symbol
  
  return current_value
```

### 核心：do_lookup_x

**源文件**: `elf/dl-lookup.c:334-518`

```
do_lookup_x(name, new_hash, old_hash, ref, result, scope, version, ...):
  
  for i = 0 to scope->r_nlist-1:
    map = scope->r_list[i]
    
    // 跳过不相关的 map
    if map == skip_map: continue
    if map 没有此类符号: continue
    
    // GNU hash 查找
    if map->l_gnu_buckets != NULL:
      sym = gnu_hash_lookup(map, name, new_hash)
    else:
      // 回退到 ELF hash
      if *old_hash == 0xFFFFFFFF:
        *old_hash = _dl_elf_hash(name)
      sym = elf_hash_lookup(map, name, *old_hash)
    
    if sym == NULL: continue
    
    // 版本匹配检查
    if !check_match(name, sym, version, map): continue
    
    // 绑定优先级
    switch ELF_ST_BIND(sym->st_info):
      case STB_GLOBAL:
        result->sym = sym
        result->map = map
        return 1              // 立即返回，全局优先
      
      case STB_WEAK:
        if result->sym == NULL:
          result->sym = sym   // 暂存弱符号
          result->map = map
        continue              // 继续寻找强符号
      
      case STB_GNU_UNIQUE:
        // 全局唯一处理
        result->sym = sym
        result->map = map
        return 1
```

### 搜索作用域

```
l_scope[0] = 全局作用域:
  [可执行文件, LD_PRELOAD库, 所有RTLD_GLOBAL库]

l_scope[1] = 本地作用域 (RTLD_LOCAL dlopen):
  [dlopen的库及其依赖]

查找顺序: scope[0] 先，scope[1] 后
同一 scope 内按 r_list[] 顺序（BFS 序）
```

## 四、符号版本化

### 版本信息结构

**源文件**: `elf/elf.h:1054-1162`

```
.gnu.version (DT_VERSYM):
  每个符号一个 uint16_t 版本索引
  
.gnu.version_d (DT_VERDEF):
  该库定义的版本（如 GLIBC_2.17, GLIBC_2.34）
  
.gnu.version_r (DT_VERNEED):
  该库需要的版本（依赖库必须提供）
```

### 版本匹配

**源文件**: `elf/dl-lookup.c:58-158`（`check_match`）

```
check_match(name, sym, version, map):
  if version == NULL:
    // 无版本要求: 接受默认版本或无版本符号
    return sym 是默认版本
  
  // 有版本要求
  symidx = sym - map->l_symtab
  map_version_idx = map->l_versyms[symidx] & 0x7FFF
  map_version = map->l_versions[map_version_idx]
  
  return version->hash == map_version->hash &&
         strcmp(version->name, map_version->name) == 0
```

### 版本化示例

```
应用调用 memcpy:
  需要版本 GLIBC_2.14 的 memcpy（最新 ABI）
  
libc.so 提供:
  memcpy@@GLIBC_2.14  (默认版本，新 ABI)
  memcpy@GLIBC_2.2.5  (旧版本，旧 ABI)
  
链接器匹配 GLIBC_2.14 版本的符号
```

## 五、IFUNC 解析

### 概念

`STT_GNU_IFUNC` 符号不直接指向实现，而是指向一个**resolver 函数**，运行时调用 resolver 选择最优实现。

### 解析流程

**源文件**: `sysdeps/generic/dl-irel.h:22-27`，`elf/dl-runtime.c:123-126`

```
重定位 IFUNC 符号时:
  resolver = sym->st_value + map->l_addr
  actual_addr = elf_ifunc_invoke(resolver)  // 调用 resolver
  *reloc_addr = actual_addr                 // 写入 GOT

resolver 函数签名:
  void* resolver(unsigned long hwcap) {
    if (hwcap & HWCAP_AVX512)
      return memcpy_avx512;
    else if (hwcap & HWCAP_AVX2)
      return memcpy_avx2;
    else
      return memcpy_sse2;
  }
```

### 应用场景

glibc 中大量使用 IFUNC：
- `memcpy`、`memset`、`strcmp`、`strlen` 等字符串函数
- 数学函数 (`libm`)
- 根据 CPU 特性（SSE4、AVX2、AVX-512）选择最快实现

## 六、符号拦截（Interposition）

### 机制

```
搜索作用域顺序决定拦截优先级:

scope = [可执行文件] → [LD_PRELOAD] → [依赖库 BFS序...]

第一个匹配的 STB_GLOBAL 符号胜出
```

### LD_PRELOAD 拦截示例

```
应用程序调用 malloc():
  1. 查找 scope[0]: 可执行文件 → 无 malloc 定义
  2. 查找 scope[0]: libpreload.so → 找到 malloc！→ 使用此实现
  3. (不再查找 libc.so 中的 malloc)
```

### RTLD_DEEPBIND

`dlopen("lib.so", RTLD_DEEPBIND)` 改变搜索顺序：
- 该库自己的 scope 优先于全局 scope
- 使库内部调用不受外部拦截影响

## 七、性能特征

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| GNU hash 查找 | O(1) 平均 | Bloom filter + 短链 |
| ELF hash 查找 | O(n/nbucket) | 链表遍历 |
| 全符号查找 | O(scope_size) | 遍历所有 map |
| Bloom filter 否定 | O(1) | 单次内存访问 |
