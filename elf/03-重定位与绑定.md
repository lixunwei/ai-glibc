# 重定位与绑定

## 一、重定位概述

重定位是动态链接的核心操作：将符号引用（编译时未知的地址）替换为运行时的实际地址。

### 重定位段

| 段 | DT 标记 | 内容 |
|----|---------|------|
| `.rela.dyn` | `DT_RELA` | 非 PLT 重定位（数据引用、GOT） |
| `.rela.plt` | `DT_JMPREL` | PLT 重定位（函数调用，可延迟） |
| `.relr.dyn` | `DT_RELR` | 压缩 RELATIVE 重定位（新格式） |

## 二、x86_64 重定位类型

**源文件**: `sysdeps/x86_64/dl-machine.h:253-482`

| 类型 | 计算公式 | 用途 |
|------|----------|------|
| `R_X86_64_RELATIVE` | `*reloc = l_addr + addend` | PIC 内部引用（最常见） |
| `R_X86_64_GLOB_DAT` | `*reloc = sym_addr` | GOT 中的全局数据 |
| `R_X86_64_JUMP_SLOT` | `*reloc = sym_addr` | PLT/GOT 中的函数 |
| `R_X86_64_64` | `*reloc = sym_addr + addend` | 绝对 64 位引用 |
| `R_X86_64_COPY` | `memcpy(reloc, sym, size)` | 主程序复制库中数据 |
| `R_X86_64_DTPMOD64` | `*reloc = tls_module_id` | TLS 模块 ID |
| `R_X86_64_DTPOFF64` | `*reloc = tls_offset` | TLS General Dynamic |
| `R_X86_64_TPOFF64` | `*reloc = tls_offset` | TLS Initial Exec |

### RELATIVE 重定位（快速路径）

**源文件**: `sysdeps/x86_64/dl-machine.h:261-264`

```c
case R_X86_64_RELATIVE:
    *reloc_addr = map->l_addr + reloc->r_addend;
    break;
```

- 不需要符号查找，只需加上加载偏移
- 占所有重定位的 70-90%
- 处理顺序最优先

### elf_machine_rela（x86_64 分发）

**源文件**: `sysdeps/x86_64/dl-machine.h:253-482`

```c
static inline void elf_machine_rela(struct link_map *map,
    const Elf64_Rela *reloc, const Elf64_Sym *sym,
    const struct r_found_version *version,
    void *const reloc_addr, ...)
{
    unsigned long r_type = ELF64_R_TYPE(reloc->r_info);
    
    if (r_type == R_X86_64_RELATIVE) {
        *reloc_addr = map->l_addr + reloc->r_addend;  // 快速路径
        return;
    }
    
    // 需要符号查找
    sym_value = _dl_lookup_symbol_x(name, map, &sym, ...);
    value = sym->st_value + sym_map->l_addr;
    
    switch (r_type) {
        case R_X86_64_GLOB_DAT:
        case R_X86_64_JUMP_SLOT:
            *reloc_addr = value;
            break;
        case R_X86_64_64:
            *reloc_addr = value + reloc->r_addend;
            break;
        case R_X86_64_COPY:
            memcpy(reloc_addr, (void*)value, sym->st_size);
            break;
        // ... TLS types ...
    }
}
```

## 四、GOT/PLT 延迟绑定

### PLT 结构（x86_64）

```asm
# PLT[0] — 公共 resolver 入口
.plt:
  push   [GOT+8]         # link_map 指针
  jmp    [GOT+16]        # _dl_runtime_resolve

# PLT[n] — 每个外部函数一个
.plt.foo:
  jmp    [GOT+foo_offset]  # 首次指向下一条指令
  push   reloc_index        # 重定位表索引
  jmp    .plt               # 跳到公共入口
```

### GOT 布局

```
GOT[0] = .dynamic 段地址
GOT[1] = link_map 指针    ← elf_machine_runtime_setup 填写
GOT[2] = _dl_runtime_resolve 地址
GOT[3] = foo 的解析地址   ← 首次调用前指向 PLT stub
GOT[4] = bar 的解析地址
...
```

### PLT 首次调用流程

```
┌─────────────────────────────────────────────────────────┐
│  调用 foo()                                              │
│    ↓                                                    │
│  jmp [GOT+foo]  → 指向 PLT stub（未解析时）             │
│    ↓                                                    │
│  push reloc_index                                       │
│  jmp PLT[0]                                             │
│    ↓                                                    │
│  push [GOT+8]   (link_map)                              │
│  jmp [GOT+16]   (_dl_runtime_resolve)                   │
│    ↓                                                    │
│  _dl_runtime_resolve:                                   │
│    保存所有寄存器（含 xsave）                             │
│    call _dl_fixup(link_map, reloc_index)                │
│    恢复寄存器                                            │
│    jmp resolved_address                                 │
└─────────────────────────────────────────────────────────┘
```

### elf_machine_runtime_setup

**源文件**: `sysdeps/x86_64/dl-machine.h:70-131`

```c
elf_machine_runtime_setup(struct link_map *l, int lazy):
  got = l->l_info[DT_PLTGOT]->d_un.d_ptr + l->l_addr;
  
  if (lazy) {
    got[1] = (ElfW(Addr)) l;                    // link_map
    got[2] = (ElfW(Addr)) &_dl_runtime_resolve; // resolver
  }
```

### _dl_runtime_resolve

**源文件**: `sysdeps/x86_64/dl-trampoline.h:32-125`

```asm
_dl_runtime_resolve:
  # 保存所有调用者保存寄存器 + 浮点/向量状态
  sub    $REGISTER_SAVE_AREA, %rsp
  mov    %rax, ... ; mov %rcx, ... ; ...
  # xsave/fxsave 如果需要
  
  # 调用 C 函数
  mov    link_map(%rsp), %rdi
  mov    reloc_index(%rsp), %rsi
  call   _dl_fixup
  mov    %rax, %r11            # 解析结果
  
  # 恢复寄存器
  mov    ..., %rax ; mov ..., %rcx ; ...
  
  # 跳转到解析后的函数
  jmp    *%r11
```

### _dl_fixup

**源文件**: `elf/dl-runtime.c:41-162`

```
_dl_fixup(link_map *l, ElfW(Word) reloc_arg):
  // 1. 定位重定位条目
  reloc = l->l_info[DT_JMPREL] + reloc_arg
  sym = &symtab[ELF64_R_SYM(reloc->r_info)]
  
  // 2. 符号查找
  result = _dl_lookup_symbol_x(strtab + sym->st_name, l, ...)
  value = result.sym->st_value + result.map->l_addr
  
  // 3. IFUNC 处理
  if (sym->st_info.type == STT_GNU_IFUNC):
    value = elf_ifunc_invoke(value)   // 调用 resolver
  
  // 4. 审计回调
  if (auditing):
    _dl_audit_symbind(...)
  
  // 5. 写入 GOT（下次直接跳转，不再经过 resolver）
  if (!GLRO(dl_bind_not)):
    *reloc_addr = value
  
  return value
```

## 六、RELRO（只读重定位）

### PT_GNU_RELRO

**源文件**: `elf/dl-reloc.c:329-348`

```
_dl_protect_relro(map):
  start = map->l_addr + map->l_relro_addr
  end = start + map->l_relro_size
  // 页对齐
  start = ALIGN_DOWN(start, pagesize)
  end = ALIGN_UP(end, pagesize)
  
  mprotect(start, end - start, PROT_READ)
```

### Partial RELRO vs Full RELRO

```
Partial RELRO (默认):
  - .got 设为只读（R_*_GLOB_DAT 已在启动时解析）
  - .got.plt 仍可写（延迟绑定需要写入）

Full RELRO (-z now):
  - 所有 GOT 在启动时解析
  - 整个 .got + .got.plt 设为只读
  - 安全性更高（GOT 覆写攻击失效）
```

## 七、初始化与析构

### 构造函数调用顺序

**源文件**: `elf/dl-init.c:25-127`（`call_init` + `_dl_init`）

```
_dl_init(main_map, argc, argv, env):
  // 1. DT_PREINIT_ARRAY（仅可执行文件有）
  if main_map->l_info[DT_PREINIT_ARRAY]:
    for each func in preinit_array:
      func(argc, argv, env)
  
  // 2. 按依赖序调用所有 DSO 的构造函数
  for each map in init_order (叶子依赖先):
    call_init(map, argc, argv, env)

call_init(map):
  // DT_INIT（旧式，单个函数）
  if map->l_info[DT_INIT]:
    init_func(argc, argv, env)
  
  // DT_INIT_ARRAY（新式，函数指针数组）
  if map->l_info[DT_INIT_ARRAY]:
    for each func in init_array:
      func(argc, argv, env)
  
  map->l_init_called = 1
```

```
_dl_fini():
```
