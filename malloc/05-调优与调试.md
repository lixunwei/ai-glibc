## 一、mallopt 参数

**源文件**: `malloc/malloc.h:119-141`，`malloc/malloc.c:5051-5108`

| 参数 | 宏名 | 默认值 | 说明 |
|------|------|--------|------|
| `M_MXFAST` | — | 160B (64位) | Fastbin 最大大小（当前版本为 no-op） |
| `M_TRIM_THRESHOLD` | 134 | 128KB | top 超过此值时 systrim |
| `M_TOP_PAD` | 135 | 0 | 扩展堆时额外预留 |
| `M_MMAP_THRESHOLD` | 136 | 128KB | 超过此值直接 mmap |
| `M_MMAP_MAX` | 137 | 65536 | 最大 mmap 映射数 |
| `M_PERTURB` | 139 | 0 | 分配/释放时填充字节 |
| `M_ARENA_TEST` | 140 | 8 | 触发 arena 限制计算的阈值 |
| `M_ARENA_MAX` | 141 | 0 (自动) | arena 最大数量 |

### 动态 mmap 阈值

**源文件**: `malloc/malloc.c:4294-4304`

```
释放 mmap chunk 时:
  if chunk_size > current_mmap_threshold:
    mmap_threshold = chunk_size       // 提高阈值
    trim_threshold = 2 * chunk_size   // 同步提高 trim 阈值
```

- 自适应调整：频繁大块分配时自动提高阈值
- `mallopt(M_MMAP_THRESHOLD, value)` 会禁用动态调整

### M_PERTURB 填充

**源文件**: `malloc/malloc.c`（alloc_perturb / free_perturb）

```
malloc 返回时: memset(ptr, perturb_byte ^ 0xFF, size)  // 填充分配
free 时:       memset(ptr, perturb_byte, size)          // 填充释放
```

- 设为非零值可帮助检测使用未初始化内存或 use-after-free

## 三、调试模式 (MALLOC_CHECK_)

### 启用方式

```bash
# 方法1: 环境变量 (仅非 SUID)
export MALLOC_CHECK_=3

# 方法2: tunable
export GLIBC_TUNABLES="glibc.malloc.check=3"

# 方法3: LD_PRELOAD (推荐)
LD_PRELOAD=libc_malloc_debug.so ./program
```

### 检查级别

| 值 | 行为 |
|----|------|
| 0 | 静默忽略错误 |
| 1 | 打印错误信息到 stderr |
| 2 | 调用 abort() |
| 3 | 打印 + abort |

### 检测内容

**源文件**: `malloc/malloc-check.c:53-239`

- 堆头部一致性（size、prev_size 匹配）
- 双重释放
- 缓冲区溢出（通过 magic bytes 在 chunk 尾部）
- 无效指针 free
- 损坏的链表指针

### 性能影响

- 开启后每次 malloc/free 增加额外校验
- 生产环境不建议开启
- 调试时配合 `M_PERTURB` 效果更好

## 五、realloc

**源文件**: `malloc/malloc.c:3357-3479`

### 算法

```
__libc_realloc(ptr, size):
  if ptr == NULL: return malloc(size)
  if size == 0: free(ptr); return NULL
  
  oldchunk = mem2chunk(ptr)
  oldsize = chunksize(oldchunk)
  
  // mmap chunk: 尝试 mremap
  if is_mmapped(oldchunk):
    if 支持 mremap:
      return mremap(oldchunk, oldsize, newsize, MREMAP_MAYMOVE)
    else:
      malloc + copy + munmap
  
  // 缩小: 如果差值足够大，切割并释放尾部
  if newsize <= oldsize:
    if oldsize - newsize >= MINSIZE:
      split_and_free_tail()
    return ptr  // 原地返回
  
  // 扩大: 检查下一 chunk 是否空闲且合并后够大
  next = chunk_at_offset(oldchunk, oldsize)
  if next == top && top + oldsize >= newsize:
    扩展 top 边界，原地扩大
  elif !inuse(next) && oldsize + nextsize >= newsize:
    合并 next，原地扩大
  else:
    malloc(new) + memcpy + free(old)
```

### 关键优化

- **mremap**: mmap chunk 可通过内核重映射避免拷贝
- **原地扩展**: 避免 memcpy（最理想情况）
- **Top chunk 扩展**: 如果紧邻 top，直接推进 top 边界

## 六、calloc

**源文件**: `malloc/malloc.c`（__libc_calloc / __libc_calloc2）

### 与 malloc+memset 的区别

```
calloc(nmemb, size):
  // 溢出检查: nmemb * size
  total = safe_multiply(nmemb, size)
  
  ptr = malloc(total)
  
  // 优化: mmap 返回的页已经是零
  if chunk_is_mmapped(ptr):
    return ptr    // 无需 memset！
  
  // 普通 chunk: 只清零用户数据部分
  memset(ptr, 0, total)
  return ptr
```

- 乘法溢出保护
- mmap 页跳过 memset（内核保证零页）
- 清零只覆盖用户请求的字节，非整个 chunk

## 七、memalign / aligned_alloc / posix_memalign

**源文件**: `malloc/malloc.c:4593-4656`

### 对齐分配算法

```
_int_memalign(arena, alignment, bytes):
  nb = request2size(bytes)
  
  // 过度分配: 预留足够空间用于对齐
  raw = _int_malloc(arena, nb + alignment + MINSIZE)
  
  // 找到对齐位置
  aligned_addr = ALIGN_UP(chunk2mem(raw), alignment)
  p = mem2chunk(aligned_addr)
  
  // 处理前面多余的部分
  if p != raw:
    leadsize = p - raw
    if leadsize >= MINSIZE:
      // 前部足够大，作为独立 chunk 合并释放
      set_head(raw, leadsize | PREV_INUSE)
      _int_free_merge_chunk(arena, raw, leadsize)
    else:
      // 前部太小，调整对齐（向后移一个对齐单位）
  
  // 处理后面多余的部分
  remainder = chunksize(p) - nb
  if remainder >= MINSIZE:
    _int_free_create_chunk(arena, remainder, ...)
    _int_free_maybe_trim(arena, ...)
  
  return chunk2mem(p)
```

### API 区别

| API | 对齐要求 | 大小要求 | 返回 |
|-----|---------|---------|------|
| `memalign(align, size)` | 2 的幂 | 任意 | 指针 |
| `aligned_alloc(align, size)` | 2 的幂 | align 的倍数 | 指针 |
| `posix_memalign(&ptr, align, size)` | ≥sizeof(void*) 且 2 的幂 | 任意 | 错误码 |
| `valloc(size)` | 页大小 | 任意 | 指针 |
| `pvalloc(size)` | 页大小 | 向上取整到页 | 指针 |

## 八、线程安全总结

| 操作 | 同步方式 | 说明 |
|------|---------|------|
| tcache_get/put | 无锁（TLS） | 纯线程本地 |
| _int_malloc/_int_free | arena->mutex | per-arena 锁 |
| arena 创建 | list_lock | 全局锁，仅在创建时 |
| free_list 操作 | free_list_lock | 轻量全局锁 |
| mallopt | — | 非线程安全（需在单线程时调用） |
| malloc_info | 逐 arena 加锁 | 遍历期间逐个锁 |

## 九、常见调优场景

### 减少内存占用

```bash
export GLIBC_TUNABLES="glibc.malloc.arena_max=2:glibc.malloc.trim_threshold=65536"
```

- 限制 arena 数量减少每 arena 的保留内存
- 降低 trim 阈值更积极归还内存

### 提高多线程性能

```bash
export GLIBC_TUNABLES="glibc.malloc.arena_max=64:glibc.malloc.tcache_count=32"
```

- 增加 arena 减少锁竞争
- 增大 tcache 容量减少 arena 访问

### 调试内存问题

```bash
export GLIBC_TUNABLES="glibc.malloc.check=3:glibc.malloc.perturb=0xAA"
# 或
LD_PRELOAD=libc_malloc_debug.so ./program
```

### 大块分配优化

```bash
export GLIBC_TUNABLES="glibc.malloc.mmap_threshold=262144"
```

- 提高阈值避免频繁 mmap/munmap（大块复用更好）
- 注意：禁用动态调整
