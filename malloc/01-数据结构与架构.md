# malloc 数据结构与架构

## 一、malloc_chunk — 内存块

**源文件**: `malloc/malloc.c:1077-1088`

```c
struct malloc_chunk {
    INTERNAL_SIZE_T mchunk_prev_size;  // 前一个chunk的大小（仅前块空闲时有效）
    INTERNAL_SIZE_T mchunk_size;       // 本chunk大小（含头部）+ 标志位

    struct malloc_chunk *fd;           // 空闲链表前向指针
    struct malloc_chunk *bk;           // 空闲链表后向指针

    struct malloc_chunk *fd_nextsize;  // 大块空闲链表（不同大小间）
    struct malloc_chunk *bk_nextsize;  // 大块空闲链表
};
```

### Chunk 内存布局

```
使用中的 chunk:                       空闲的 chunk:
┌────────────────────────┐            ┌────────────────────────┐
│ prev_size (前块空闲时)  │            │ prev_size              │
├────────────────────────┤            ├────────────────────────┤
│ size      | N|M|P      │            │ size      | N|M|P      │
├────────────────────────┤  ←chunk    ├────────────────────────┤
│                        │            │ fd                     │
│   用户数据 (payload)    │            ├────────────────────────┤
│                        │            │ bk                     │
│                        │            ├────────────────────────┤
│                        │            │ fd_nextsize (large only)│
│                        │            ├────────────────────────┤
│                        │            │ bk_nextsize (large only)│
├────────────────────────┤            ├────────────────────────┤
│ next chunk's prev_size │            │ (空闲空间...)           │
└────────────────────────┘            └────────────────────────┘
```

### 标志位（size 字段低 3 位）

**源文件**: `malloc/malloc.c:1287-1310`

| 位 | 名称 | 值 | 含义 |
|----|------|-----|------|
| bit 0 | `PREV_INUSE` | 0x1 | 前一个 chunk 正在使用中 |
| bit 1 | `IS_MMAPPED` | 0x2 | 该 chunk 由 mmap 直接分配 |
| bit 2 | `NON_MAIN_ARENA` | 0x4 | 属于非主 arena |

```c
#define SIZE_BITS (PREV_INUSE | IS_MMAPPED | NON_MAIN_ARENA)  // 0x7
#define chunksize(p) (chunksize_nomask(p) & ~SIZE_BITS)
```

### 大小规则

**源文件**: `malloc/malloc.c:1217-1251`

```
CHUNK_HDR_SZ = 2 * SIZE_SZ = 16 (64位)
MIN_CHUNK_SIZE = offsetof(malloc_chunk, fd_nextsize) = 32 (64位)
MINSIZE = aligned(MIN_CHUNK_SIZE) = 32

request2size(req):
  req + CHUNK_HDR_SZ + MALLOC_ALIGN_MASK) & ~MALLOC_ALIGN_MASK
  结果至少为 MINSIZE

示例(64位): request=1~24 → chunk=32, request=25~40 → chunk=48
```

## 二、malloc_state — Arena 状态

**源文件**: `malloc/malloc.c:1715-1750`

```c
struct malloc_state {
    __libc_lock_define(, mutex);       // arena 互斥锁
    int flags;                         // 状态标志
    
    mchunkptr top;                     // top chunk（虚拟的巨大空闲块）
    mchunkptr last_remainder;          // 最近分割产生的剩余块
    
    mchunkptr bins[NBINS * 2 - 2];    // 所有 bin 的头节点数组
    unsigned int binmap[BINMAPSIZE];   // bin 非空位图
    
    struct malloc_state *next;         // arena 环形链表
    struct malloc_state *next_free;    // 空闲 arena 链表
    
    INTERNAL_SIZE_T attached_threads;  // 绑定的线程数
    INTERNAL_SIZE_T system_mem;        // 当前从系统获取的内存
    INTERNAL_SIZE_T max_system_mem;    // 峰值
};
```

### main_arena

**源文件**: `malloc/malloc.c:1794-1805`

```c
static struct malloc_state main_arena = {
    .mutex = _LIBC_LOCK_INITIALIZER,
    .next = &main_arena,
    .attached_threads = 1
};
```

- 静态分配，使用 `sbrk()` 扩展堆
- `next` 指向自己形成环形链表

## 三、heap_info — 二级 Arena 堆头

**源文件**: `malloc/arena.c:67-79`

```c
typedef struct _heap_info {
    mstate ar_ptr;              // 所属 arena
    struct _heap_info *prev;    // 同 arena 的前一个 heap
    size_t size;                // 当前 heap 映射大小
    size_t mprotect_size;      // mprotect 保护的大小
    size_t pagesize;           // 页大小
    char pad[...];             // 对齐填充
} heap_info;
```

### 二级 Arena 堆布局

```
┌──────────────────────────────────────────────┐
│                HEAP_MAX_SIZE (64MB)            │
├──────────┬───────────────────────────────────┤
│heap_info │ malloc_state │    chunk area       │
│  (头部)  │  (arena)     │  ← top chunk →     │
└──────────┴───────────────────────────────────┘
     ↕ prev
┌──────────┬───────────────────────────────────┐
│heap_info │         chunk area                 │
└──────────┴───────────────────────────────────┘
```

- 每个 heap 最大 `HEAP_MAX_SIZE`（64位系统为 64MB）
- arena 状态位于第一个 heap 的 heap_info 之后
- 多个 heap 通过 `prev` 指针链接

## 四、Bin 体系

### 概览

**源文件**: `malloc/malloc.c:1462-1579`

```
bins[0..253]:
  bin[0]      — 未使用
  bin[1]      — unsorted bin（大 chunk 释放/合并后的暂存处）
  bin[2..64]  — small bins（精确大小，双向循环链表）
  bin[65..127]— large bins（大小范围，按大小排序）
```

| Bin 类型 | 数量 | 大小范围（64位） | 结构 | 查找方式 |
|---------|------|----------------|------|---------|
| Unsorted | 1 | 任意 | 双向链表 | 顺序扫描 |
| Small | 62 | 32~1008 (步长16) | 双向循环 | 精确索引 |
| Large | 63 | 1024~∞ | 排序双向 + nextsize | best-fit |

### Small Bins

**源文件**: `malloc/malloc.c:1533-1544`

```
NSMALLBINS = 64
SMALLBIN_WIDTH = MALLOC_ALIGNMENT = 16

smallbin_index(sz) = sz / SMALLBIN_WIDTH
  bin[2]  → 32 字节
  bin[3]  → 48 字节
  ...
  bin[63] → 1008 字节
```

- 精确大小匹配，FIFO（从 last 取出）
- 双向循环链表，O(1) 插入/删除

### Large Bins

**源文件**: `malloc/malloc.c:1546-1579`

```
大小分组（64位）:
  bin[65..96]  — 每 64 字节一组 (32 bins, 1024~3072)
  bin[97..112] — 每 512 字节一组 (16 bins)
  bin[113..120]— 每 4096 字节一组 (8 bins)
  bin[121..124]— 每 32768 字节一组 (4 bins)
  bin[125..126]— 每 262144 字节一组 (2 bins)
  bin[127]     — 剩余所有
```

- 同一 bin 内按大小**降序**排列
- 使用 `fd_nextsize`/`bk_nextsize` 跳过相同大小的块（加速查找）

### Unsorted Bin

**源文件**: `malloc/malloc.c:1529-1530`

```c
#define unsorted_chunks(M) (bin_at(M, 1))
```

- 所有刚释放（合并后）的 chunk 先放入此处
- malloc 时遍历此 bin：精确匹配直接返回，否则放入对应 small/large bin
- 扮演**缓冲区**角色，利用时间局部性

### Bin 操作宏

**源文件**: `malloc/malloc.c:1497-1507`

```c
#define bin_at(m, i)  (&(m)->bins[(i-1)*2])  // bin 头地址
#define first(b)      ((b)->fd)               // 第一个 chunk
#define last(b)       ((b)->bk)               // 最后一个 chunk
```

### binmap 位图

**源文件**: `malloc/malloc.c:1732-1733`

- 每个 bit 对应一个 bin 是否非空
- 用于快速跳过空 bin，在 large bin 分配时进行 bit 扫描

## 五、Tcache 结构

**源文件**: `malloc/malloc.c:2864-2907`

```c
typedef struct tcache_entry {
    struct tcache_entry *next;     // 单链表
    uintptr_t key;                // 双重释放检测 cookie
} tcache_entry;

typedef struct tcache_perthread_struct {
    uint16_t num_slots[TCACHE_MAX_BINS];  // 每 bin 剩余可用计数
    tcache_entry *entries[TCACHE_MAX_BINS]; // bin 头指针
} tcache_perthread_struct;

static __thread tcache_perthread_struct *tcache;
```

### Tcache 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TCACHE_MAX_BINS` | 76 (64+12) | bin 总数 |
| `TCACHE_FILL_COUNT` | 16 | 每 bin 默认容量 |
| `tcache_key` | random | 进程级随机 cookie |

## 六、关键尺寸总结（64 位）

```
┌─────────────────────────────────────────────────────┐
│  0       32      1008    1024          128KB+       │
│  ├───────┼────────┼───────┼─────────────┼──────→    │
│  │tcache │tcache  │       │             │           │
│  │+small │+small  │ large │   large     │  mmap     │
│  │ bins  │ bins   │  bins │   bins      │  直接映射 │
│  └───────┴────────┴───────┴─────────────┴──────→    │
│                                                     │
│  Tcache: 32~1216 字节 (76 bins × 16B 步长)         │
│  Small:  32~1008 字节 (62 bins × 16B 步长)         │
│  Large:  1024~∞ 字节 (63 bins, 对数分组)           │
│  Mmap:   ≥128KB (默认阈值, 可动态调整)             │
└─────────────────────────────────────────────────────┘
```
